# Git Day 1 - Basics

## What is Git?

Git is a Distributed Version Control System (DVCS).

It helps developers:
- Track changes in files.
- Save different versions of a project.
- Collaborate with other developers.
- Restore previous versions if something goes wrong.

---

## What is GitHub?

GitHub is an online platform that hosts Git repositories.

Git = Version Control Software (installed on your computer)

GitHub = Cloud platform where Git repositories are stored and shared.

---

# Important Terms

## Repository (Repo)

A project folder managed by Git.

---

## Working Directory

The folder where you currently create and edit files.

---

## Staging Area

A temporary area where Git stores files before committing them.

Think of it as a "Ready to Submit" area.

---

## Commit

A snapshot of your project at a specific point in time.

Every commit has:
- A unique ID
- A commit message
- A timestamp
