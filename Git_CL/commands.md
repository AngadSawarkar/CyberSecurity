1) git --version

Syntax:
git --version

Meaning:
Displays the currently installed version of Git.

Example:
git --version

--------------------------------------------------

2) pwd

Full Form:
Print Working Directory

Syntax:
pwd

Meaning:
Displays the current directory (folder) you are working in.

Example:
pwd

--------------------------------------------------

3) ls

Full Form:
List

Syntax:
ls

Meaning:
Lists all files and folders present in the current directory.

Example:
ls

--------------------------------------------------

4) cd

Full Form:
Change Directory

Syntax:
cd <folder_name>

Meaning:
Moves from the current directory to another directory.

Example:
cd Desktop

Example:
cd Git

--------------------------------------------------

5) mkdir

Full Form:
Make Directory

Syntax:
mkdir <folder_name>

Meaning:
Creates a new directory (folder).

Example:
mkdir CyberSecurity

--------------------------------------------------

6) touch

Syntax:
touch <file_name>

Meaning:
Creates an empty file.

Example:
touch README.md

--------------------------------------------------

7) code .

Syntax:
code .

Meaning:
Opens the current folder in Visual Studio Code.

Note:
"." represents the current directory.

--------------------------------------------------

8) git init

Syntax:
git init

Meaning:
Initializes the current folder as a Git repository.

Example:
git init

--------------------------------------------------

9) git status

Syntax:
git status

Meaning:
Displays the current status of the Git repository.

It shows:
• Current branch
• Modified files
• Untracked files
• Staged files
• Files ready to commit

Example:
git status

--------------------------------------------------

10) git add

Syntax:
git add <file_name>

Meaning:
Adds a file to the Staging Area so Git can include it in the next commit.

Example:
git add README.md

To add all files:
git add .

--------------------------------------------------

11) git commit

Syntax:
git commit -m "Commit Message"

Meaning:
Creates a snapshot (saved version) of the staged files.

Example:
git commit -m "Add initial README"

--------------------------------------------------
