# Module 1

> Shodan(TryScanMe)
Shodan is a search engine for the IoT. it scans the internet, searching for networking equipment, industrial control systems, traffic cameras, and virtually anything else with a public network connection to see what's running and where.

> VirusTotal(TryDetectMe)
    .It collects results from the anti virus engines adn tell whether any file is malicious or not. Used in Blue Teaming to know about the file.

> Common vulnerabilities and Exposure(CVE)
    .A dictionary which has every known vulnerabilities listed in it.

    .Score is given on the factors:
        Impact - What damage can this vulnerability lead to?
        
        Complexity - Is the vulnerability easy to exploit or not? 
        
        Availability - How likely is it that someone can exploit this?

> MAN
    .Command used in linux cml to get the description (Manual) os any command present in the Linux cml.

> git Hub
    .Git Hub can also be used to search for vulnerabilities their threat level, tools used etc.
