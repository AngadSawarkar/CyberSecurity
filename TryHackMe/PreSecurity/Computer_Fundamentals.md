> Virtualisation
    Virtualization is a technology that allows multiple virtual computers or operating systems to run on a single physical computer by sharing its hardware resources. It creates a virtual version of hardware, storage, network, or an operating system, improving resource utilization and reducing costs.

A software called a hypervisor (or Virtual Machine Monitor) manages the virtual machines (VMs). Each VM works independently and can run a different operating system.

Types of Virtualization:

Server Virtualization – Multiple virtual servers run on one physical server.
Desktop Virtualization – Desktops are hosted centrally and accessed remotely.
Storage Virtualization – Combines multiple storage devices into one logical storage unit.
Network Virtualization – Creates virtual networks independent of physical hardware.

Advantages:

Better hardware utilization
Lower infrastructure and maintenance costs
Easy backup and disaster recovery
Improved scalability and flexibility
Safe environment for software testing and development

Examples of Virtualization Software:

VMware Workstation
Oracle VirtualBox
Microsoft Hyper-V
KVM (Kernel-based Virtual Machine)

Applications:
Virtualization is widely used in cloud computing, data centers, software testing, cybersecurity labs, and server consolidation.
