# Module 5 - Networking Fundamentals

## 1. What is Networking?

### Definition
Networking is the process of connecting two or more devices to share data and resources.

### Advantages
- File Sharing
- Internet Access
- Communication
- Resource Sharing

### Types of Networks
- LAN (Local Area Network)
- MAN (Metropolitan Area Network)
- WAN (Wide Area Network)

---

## 2. Introduction to LAN

### What is LAN?
A Local Area Network (LAN) connects devices within a limited area such as a home, office, or school.

### Common Devices
- Router
- Switch
- Hub
- Access Point
- Computer

### Network Topologies
- Star
- Bus
- Ring
- Mesh

---

## 3. OSI Model

| Layer | Name |
|-------|------|
| 7 | Application |
| 6 | Presentation |
| 5 | Session |
| 4 | Transport |
| 3 | Network |
| 2 | Data Link |
| 1 | Physical |

### Purpose
The OSI model explains how data travels across a network.

---

## 4. Packets and Frames

### Packet
- Unit of data at the **Network Layer (Layer 3)**
- Contains source and destination IP addresses.

### Frame
- Unit of data at the **Data Link Layer (Layer 2)**
- Contains source and destination MAC addresses.

### Encapsulation
Data is wrapped with headers as it moves down the OSI layers and unwrapped at the destination.

---

## 5. Extending Your Network

### Router
Connects different networks and forwards packets.

### Switch
Connects devices within the same LAN using MAC addresses.

### Hub
Broadcasts data to all connected devices.

### Access Point (AP)
Provides wireless (Wi-Fi) connectivity.

### Repeater
Regenerates signals to extend network range.

### Bridge
Connects two LAN segments.

## Key Takeaways

- Networking allows devices to communicate and share resources.
- LAN is used for small/local networks.
- The OSI Model has **7 layers**.
- Packets operate at **Layer 3**, Frames at **Layer 2**.
- Routers, switches, and access points help build and extend networks.
