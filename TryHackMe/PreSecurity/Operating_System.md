# Module 3 - Operating System Basics

## 1. Operating System (OS) Introduction

### What is an Operating System?
An Operating System (OS) is system software that manages computer hardware and software resources and provides an interface between the user and hardware.

### Main Functions
- Process Management
- Memory Management
- File Management
- Device Management
- User Management
- Security Management

### Examples
- Windows
- Linux
- macOS
- Android

## 3. Linux Command Line (CLI)

### What is CLI?
A text-based interface used to interact with Linux.

### Basic Commands

| Command | Purpose |
|---------|---------|
| `pwd` | Show current directory |
| `ls` | List files |
| `cd` | Change directory |
| `mkdir` | Create directory |
| `rmdir` | Remove directory |
| `touch` | Create file |
| `rm` | Delete file |
| `cp` | Copy files |
| `mv` | Move/Rename files |
| `cat` | Display file contents |
| `clear` | Clear terminal |
| `man` | View command manual |

## Key Takeaways

- OS manages hardware and software resources.
- Windows is the most widely used desktop OS.
- Linux is widely used in servers and cybersecurity.
- Learn basic Linux and Windows CLI commands.
- Keep systems secure using updates, firewalls, antivirus, and strong authentication.
