# Module 4 - Software Basics

## 1. Data Representation

### What is Data Representation?
Data representation is the method of storing and processing data in a computer.

### Number Systems
- Binary (Base 2)
- Decimal (Base 10)
- Octal (Base 8)
- Hexadecimal (Base 16)

### Units of Data
- Bit
- Nibble (4 bits)
- Byte (8 bits)
- KB
- MB
- GB
- TB

---

## 2. Data Encoding

### What is Data Encoding?
The process of converting data into a format that computers can store and process.

### Common Encoding Standards
- ASCII
- Unicode
- UTF-8

### Common Data Formats
- Text
- Images
- Audio
- Video

## 3. Python (Simple Demo)

### What is Python?
A high-level, interpreted programming language widely used in automation, scripting, web development, AI, and cybersecurity.

### Basic Syntax

```python
print("Hello, World!")
```

### Variables

```python
name = "Alice"
age = 20
```

### Input

```python
name = input("Enter your name: ")
```

### Conditional

```python
if age >= 18:
    print("Adult")
```

---

## 4. JavaScript (Simple Demo)

### What is JavaScript?
A scripting language used to make web pages interactive.

### Basic Syntax

```javascript
console.log("Hello, World!");
```

### Variables

```javascript
let name = "Alice";
const age = 20;
```

### Conditional

```javascript
if (age >= 18) {
    console.log("Adult");
}
```

## 5. Database & SQL Basics

### What is a Database?
A collection of organized data.

### Types
- Relational Database
- NoSQL Database

### Common DBMS
- MySQL
- PostgreSQL
- SQLite
- Microsoft SQL Server

### Basic SQL Commands

| Command | Purpose |
|---------|---------|
| `CREATE DATABASE` | Create a database |
| `CREATE TABLE` | Create a table |
| `INSERT INTO` | Insert data |
| `SELECT` | Retrieve data |
| `UPDATE` | Modify data |
| `DELETE` | Delete data |
| `DROP TABLE` | Delete a table |

### Example

```sql
SELECT * FROM students;
```

## Key Takeaways

- Python is beginner-friendly and widely used in cybersecurity.
